# StageCue · 演出音控台

可离线运行的演出音乐与音效播放工具，使用 HTML、CSS 和原生 JavaScript 构建，无需安装依赖或启动服务器。

## 下载与启动

[直接下载 StageCue-Offline.zip](https://github.com/Alan-duan1995/stagecue/raw/refs/heads/main/downloads/StageCue-Offline.zip)，解压后使用桌面版 Chrome 或 Edge 打开 `StageCue.html`。

也可以下载本仓库的 ZIP，解压后直接打开 `StageCue.html`。

## 功能

- 本地音频导入与浏览器本地保存
- 音效垫触发、分类、名称与颜色编辑
- 播放队列与自动续播
- 单曲切换、音效叠加与循环播放
- 淡入淡出、主音量、紧急停止
- 包含音频文件的演出备份与恢复
- 12 个内置合成试听素材

## 快捷键

| 按键 | 操作 |
| --- | --- |
| 1–9 / Q / W / E | 触发前 12 个音频 |
| 空格 | 播放 / 暂停 |
| Esc | 停止所有声音 |
| ← / → | 上一首 / 下一首 |
| 右键音效垫 | 编辑、加入队列或删除 |

## 数据保存

音乐文件在当前浏览器内保存，不会上传。请保持浏览器和 HTML 文件路径不变；浏览器清理、隐私模式或存储限制可能导致数据不可用。重要演出请导出包含音频的演出备份。

## 验证与使用范围

已完成 JavaScript 语法及模拟音频接口的逻辑检查，包括播放、单曲切换、叠加、循环、音量、暂停恢复和紧急停止。尚未在实际电脑与声卡上完成试听，正式演出前请自行测试。

本项目是独立的浏览器工具，与 Sports Sound Pro 无关联。它不是 Windows EXE，也不提供专业音频驱动、多声卡路由或延迟保证。
