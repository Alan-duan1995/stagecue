# StageCue 2 · 演出音乐与音效控制台

署名：**中东中亚IT SSC   Alan**

可离线使用的演出音控工具：本地音频导入、独立电平、流程 GO、裁切播放与双 Deck 转场。

## 下载

- **[HTML 离线版](https://github.com/Alan-duan1995/stagecue/raw/refs/heads/main/downloads/StageCue-Offline.zip)**：解压后用桌面版 Chrome 或 Edge 打开 `StageCue.html`，无需安装或启动服务器。
- **[Windows x64 原生启动程序](https://github.com/Alan-duan1995/stagecue/raw/refs/heads/main/downloads/StageCue-Windows-x64-v2.0.1.zip)**：解压后运行 `StageCue.exe`。需要电脑已安装 Microsoft Edge 或 Google Chrome；程序会打开独立应用窗口，并使用固定的本地数据目录。

Windows 2.0.1 包使用约 90 KB 的 C / Win32 原生启动器，替换此前 Node 封装，并附带 HTML 备用入口和启动诊断工具；无需 Node 运行时。已在 Wine 兼容环境运行，验证页面提取与浏览器启动参数，尚未在真实 Windows 上运行 Edge 窗口。HTML 音频与交互已在 Chromium 中完成自动检查；实际声卡仍需现场测试。

## v2 功能

| 功能 | 用法 |
| --- | --- |
| 每首独立音量与增益记忆 | 音效垫底部调整 0–100% 音量；编辑窗口设置 −24 至 +12 dB 增益，自动保存 |
| 入点 / 出点 | 编辑音频时输入秒数，或从正在播放的位置标记；预听也遵循裁切区间 |
| 双 Deck 交叉淡变 | 触发模式选择“交叉淡变”，新曲淡入、旧曲淡出；原有单曲切换和叠加模式继续保留 |
| 独立耳机预听 | 在音频路由明确选择两台不同设备，点击单曲“预听”；预听不进入主混音 |
| 演出流程表与 GO | 点击单曲 ＋ 加入流程，排序、添加主持备注，GO 或 Enter 执行下一条；最后一条自动续播结束后不会回到开头 |
| 演出锁定 | 禁止编辑、删除、导入恢复、音量修改和流程重排；保留触发、GO、播放控制、主持压低、预听和紧急全停 |
| 剩余时间与预警 | 显示裁切区间的剩余时间；可设 5 / 10 / 15 / 30 秒预警，最后 5 秒变红 |
| 主持压低 | 一键按设定幅度压低主混音，再点击平滑恢复；不会改写单曲音量 |
| 素材预检 | 实际解码音频，检查缺失、无效裁切、头尾长静音与增益下可能削波；可导出 JSON 报告 |
| Windows 本地启动 | 独立窗口、固定数据目录；源码和可复现构建步骤见 `desktop/` |

仍支持：音效分类与颜色编辑、循环、单曲淡入淡出、紧急停止、演出备份恢复，以及 12 个合成试听音频。

## 推荐操作顺序

1. 导入自己的音乐；编辑名称、颜色、分类、增益和入点 / 出点。
2. 在每个音效垫上校准独立音量，观察 RMS / 峰值，避免红色削波提示。
3. 点击 ＋ 加入演出流程，设置顺序与主持备注；点击条目编号可设为下一条。
4. 有独立声卡时，在“音频路由 / 耳机”明确选择主输出与耳机设备；实机试听确认。
5. 停止播放，执行“演出前素材检查”，检查报告，然后导出演出备份。
6. 开启演出锁定；通过音效垫或 GO 控制现场。

## 快捷键

| 按键 | 操作 |
| --- | --- |
| 1–9 / Q / W / E | 触发前 12 个音频 |
| 空格 | 当前音轨播放 / 暂停 |
| Enter | GO，执行下一条流程 |
| Esc | 停止全部音轨与耳机预听 |
| ← / → | 上一条 / 下一条流程 |
| 右键音效垫 | 编辑单曲设置 |

## 电平与声卡输出

每首音乐显示 RMS 条、采样峰值线和峰值 dBFS 数值，电平条范围为 −60 至 0 dBFS。测量位置在单曲音量、增益与淡变之后，主音量之前。暂停 / 停止显示 −∞ dBFS。同一首重复叠加时显示实例 RMS / 峰值最大值。主输出两列表分别显示混音 RMS 和峰值。

电平来自浏览器的单声道采样分析，不是左右声道独立电平、真峰值或 LUFS 响度表。素材检查的静音阈值为 −60 dBFS，超过 1 秒会提示；检测是辅助检查，不替代试听。

设备选择依赖浏览器的 `setSinkId` 支持和系统权限。默认输出模式下禁止耳机预听；只有明确指定两个不同输出 ID 后才启用预听。浏览器可能需要一次麦克风授权才能显示设备名称，此授权仅用于枚举设备，不保存录音。输出路由每次打开都需重新确认；检测到所选设备消失会停止所有声音。此版本不提供 ASIO、多通道硬件混音或实时延迟保证。

## 数据保存与升级

- 音频文件与单曲设置保存在当前浏览器的 IndexedDB 中，不上传。
- HTML 版请保持浏览器与文件路径不变。浏览器清理、隐私模式和存储限制可能导致数据不可用。
- **替换旧版本前先“导出演出备份”**；新版支持恢复 v1 / v2 备份，新备份使用 v2 格式。
- 备份包含音乐文件、独立音量、增益、入点 / 出点、流程顺序与备注及全局设置；设备路由和锁定状态不写入备份。
- Windows 启动程序使用 `%LOCALAPPDATA%\StageCue\BrowserProfile` 专用数据目录；从 HTML 版迁移时请恢复演出备份。
