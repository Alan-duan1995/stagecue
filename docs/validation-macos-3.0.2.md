# Mac 3.0.2 波形与大号时间验证

日期：2026-11-15。构建提交：`8be5f1dfbe712ad23953f84de5912b99f58f515c`。

[原生 Mac 构建与检查](https://github.com/Alan-duan1995/stagecue/actions/runs/43690174909) 已成功；Apple 芯片与 Intel 均在对应架构的 macOS 15 构建机直接运行打包后的 StageCue.app。

- 全采样峰值、立体声 RMS、单采样脉冲、分块边界和静音检查通过；没有将每首曲子的峰值自动放大归一化。
- 使用已知强弱分布的双声道 WAV，检查四段源幅度的波形结果、完整八秒范围、入点/出点、变速、暂停、进度位置、播放结束位置。
- 检查大号剩余时间、已播/总长字体、鼠标位置提示、快速切歌取消过期结果，以及波形无法生成时播放和全停仍正常。
- 两类 Mac 的基本播放、AudioWorklet/DSP、素材库/Range、控制服务、备份和重启持久化检查通过。
- 共享代码在 Linux/X11 的高级客户端与自动化检查通过，包含 Monitor 隔离、编辑器、素材同步、定时播报与紧急全停。
- 两类应用签名完整性、DMG 校验及 ZIP 数据检查通过。运行环境要求 macOS 13 或更新版本。
