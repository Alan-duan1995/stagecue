# Mac 3.1.1 年会工作台验证

日期：2026-11-15。构建提交：`52c71e8aabbd3ef644a42ba3f4fdbdae0489a3a6`。

[原生 Mac 构建与检查](https://github.com/Alan-duan1995/stagecue/actions/runs/43694796861) 成功。Apple 芯片与 Intel 都直接运行了对应架构打包后的 StageCue.app。

## 新功能检查

- 默认简洁演出界面，准备区功能保留，演出锁定生效。
- 点选音效只待命；GO / Enter 执行，连续 GO 有防重复保护。
- 主持压低在顶部可见，检查了 820 px 窄窗口；准备区的分类和搜索不会隐藏返回演出后的音效。
- 添加、编辑讲话与颁奖环节，关联音频、计划时长、备注和淡变模式。
- 无音频讲话环节只开始计时，已有背景音乐继续播放；超时变红。
- 暂停节目计时不暂停音乐；全停停止声音、暂停计时并保留流程。
- 保存和重启保留流程，不自动播音、计时或恢复临时待命。
- 演出备份保留年会流程数据。

## 保留功能检查

两类 Mac 的播放、AudioWorklet/DSP、素材库、Range 流、控制服务、备份、重启持久化、整曲波形、大号时间、快切取消及波形失败隔离均通过。

共享代码在 Linux/X11 检查了高级编辑器、Monitor 隔离、定时播报与压低恢复、全停、备份与迁移、文件菜单、隔离配置及离线策略。

两种应用代码签名完整性、DMG 校验及 ZIP 数据检查通过。下载公开 DMG 后匿名重新校验：

要求 macOS 13+；检查环境为 macOS 15。当前为本地 ad-hoc 签名，未做 Apple Developer ID 签名或公证。外接声卡、现场延迟与声音质量、实体 Stream Deck 仍需在演出设备上验收。

自动双机切换、导演提示屏、Excel 台本导入和视频/灯光时码联动均未实现，详见 [功能说明与后续建议](annual-show.md)。
