# Sports Sounds Pro 8 功能对照与验收

参考：[Sports Sounds Pro 官方功能页](https://www.sportssoundspro.com/uploads/)（核对日期：2026-11-14）。StageCue 是独立实现，与原厂无关联；3.0 不代表完整功能等同或原厂格式认证。

| 功能领域 | StageCue 3.0 实现 | 已完成验证 / 实际限制 |
| --- | --- | --- |
| 音效板 | 每页 48 键、分组分页拖动、颜色、已用状态、快捷键、页面目录复用和导入导出 | 实际 Electron 页面、保存和目录操作 |
| 播放 | 单曲切换、叠加、交叉淡变、随机、列表循环、GO、淡入淡出、压低、全停 | 实际数字音频播放；声卡延迟未做 Windows 实机测量 |
| 单曲电平 | 每首 RMS / 采样峰值、独立音量和增益 | 播放中实时分析；不是真峰值表 |
| 音频编辑 | 可缩放波形与裁切、10 段 EQ、卷积混响、独立变调与变速 | 实际 DSP 频率 / 时长 / 混响尾音测试；非破坏性参数编辑，不是通用多轨 DAW |
| LUFS | K 加权、绝对和相对门限、效果后离线分析、目标增益 | 单声道 / 双声道结果对照 FFmpeg；使用 −1 dBFS 采样峰值限幅，非真峰值限制器；短于 400 ms 不分析 |
| 素材库同步 | 授权文件夹监测、重命名和根目录移动识别、离线保留、手动重连、元数据写回与原文件备份 | 真实文件索引 / 重命名 / Unicode 标签写回 / 恢复测试；移动至其他未授权目录需主动重连；依赖音频格式支持 |
| Monitor | 独立耳机试听、私有队列、私有播放控制与草稿，应用到未来现场触发 | 主 / 私有音频图与编辑隔离测试；需明确选择两个不同输出，真实硬件分流待验 |
| 自动化 | 指定日期时间或延迟执行音效 / 列表、模式选择、背景压低与播报旁路 | 主输出播报、压低恢复、每轨循环隔离、全停取消测试；仅客户端运行时执行，重启默认解除武装，迟到超过 5 秒跳过 |
| 比赛工具 | 正倒计时、运动预设、节次、结束音效、比分、阵容和出场顺序、笔记 | Electron 交互与时钟检查；不接外部体育数据源 |
| Quick Panel 社交 | 复制现场简报、在浏览器打开社交发布草稿 | 用户自行确认发布；未实现原厂可能提供的账号集成或直接自动发布 |
| 主题管理 | 多类部件的颜色、字体、尺寸等属性、即时预览、导入导出 | 合法外观值校验；布局和部件与原厂不同 |
| Stream Deck | 配对插件、当前页 / 固定音效、状态颜色、多设备、播放和页面命令、音量 / 变调 / 速度 / 混响旋钮 | Elgato 官方 CLI 校验和打包；真实插件进程与 SDK 协议、多设备状态测试；实物设备待验。需 Stream Deck 7.1+ |
| 旧 `.SET` 导入 | **未实现** | 缺少真实样本和格式规范；需要用户提供原厂导出的样本，不能宣称兼容 |
| macOS 安装（3.0.1） | Apple 芯片 / Intel DMG 与 ZIP、本地签名、Mac 菜单和权限说明 | macOS 13+；由两类原生 Mac 构建机打包与检查，详见 [Mac 验证记录](validation-macos-3.0.1.md)；外接声卡和实体控制器待验 |
| Windows 安装 | 内置 Electron、中文安装向导、快捷方式、卸载、保留数据 | 安装器和载荷 CRC、运行环境、资源、源码核对；真实 Windows 安装与声卡待验，当前未签名 |

音频格式以 Chromium 实际支持为准；未提供 ASIO、原厂硬件驱动或原厂插件兼容层。自动测试的模拟设备、协议验证不能替代实机演出验收。
