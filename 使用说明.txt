StageCue 2.0 · 本地演出音控台
署名：中东中亚IT SSC   Alan

【启动】
HTML 版：解压到固定文件夹，用桌面版 Chrome 或 Edge 打开 StageCue.html，断网可用，无需服务器。
Windows x64 版：运行 StageCue.exe；需要已安装 Edge 或 Chrome。程序会使用独立窗口和固定的本地数据目录。当前 EXE 已构建并核对结构及启动逻辑，尚未在 Windows 实机运行。

【升级与备份】
替换旧版前先导出演出备份。新版支持恢复 v1 / v2 备份。
HTML 和 Windows 版使用不同存储位置，首次切换请通过备份迁移。
音乐保存在当前浏览器，不上传。浏览器清理、隐私模式和移动 HTML 文件路径可能导致原有数据不可用。
重要演出请导出含音乐的演出备份。

【单曲设置】
每个音效垫有独立音量，编辑中可设置增益和入点 / 出点。
入点 / 出点以秒为单位，出点留空表示播放到结尾。修改裁切在下一次触发时生效。
RMS 条、白色采样峰值线与 dBFS 数字显示单曲音量及淡变后的电平；主音量不影响单曲表。同曲重复触发时显示实例最大值。
循环仅在裁切区间内播放。

【转场与主持】
单曲切换：新曲准备好后停止旧曲；音效叠加：同时播放多个音效；双 Deck 交叉淡变：新曲淡入、旧曲淡出，时间可设置。
“主持讲话”按设定 dB 压低主混音，再点击恢复，不修改单曲音量。

【流程与锁定】
点击音效垫 ＋ 加入演出流程；支持上下移动与备注。
点击条目编号设为下一条；GO / Enter 执行下一条。
自动继续只按流程向后执行，最后一条结束后停止，不回到开头。
演出锁定禁用编辑、删除、导入、音量调整与流程重排，保留播放、GO、压低和紧急全停。
倒计时对应裁切区间剩余时间，可配置结束预警，最后 5 秒变红。

【耳机预听】
在“音频路由 / 耳机”中明确选择两台不同的主输出与耳机设备，才能开启预听。
依赖浏览器输出设备选择支持。默认输出模式下禁用预听。
可能需要一次麦克风授权来获取设备列表；不保存录音。
设备路由每次打开需重新确认。主播放与预听图隔离，预听出错不应中断主播放；检测到所选设备移除时会停止全部声音。
真实声卡分流尚未完成硬件验收，请在实际电脑上确认耳机声音不会进入现场输出。

【素材预检】
停止播放后点击“演出前素材检查”：检查解码、缺失文件、裁切范围、头尾长静音与增益下可能削波，可导出报告。
这不是 LUFS / 真峰值检测，仍需试听。

【快捷键】
1–9 / Q / W / E：触发前 12 个音频
空格：当前音轨播放 / 暂停
Enter：GO
Esc：停止全部声音，含耳机预听
左右方向键：上一条 / 下一条流程
右键音效垫：编辑设置

内置音频是合成试听素材。正式演出请导入自己的音频，并提前测试实际电脑与声卡输出。
